# telegram-tui

Терминальный клиент для Telegram на [Textual](https://textual.textualize.io/).
Работает на **mock-engine** — полной симуляции активности аккаунта — поэтому
клиент можно запустить и тестировать прямо сейчас, без реальной авторизации.

![Скриншот клиента](docs/screenshot.png)

## Запуск

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
pip install -e .
telegram-tui          # или: python -m telegram_tui
```

## Интерфейс — три панели

| Панель | Что умеет |
|---|---|
| Слева: список чатов | поиск (`/` или `Ctrl+F`), пины (`Ctrl+P`), счётчик непрочитанных (циановый бейдж), превью последнего сообщения, иконки типа (группа/канал) |
| Центр: история сообщений | скролл, подсветка синтаксиса кода (fenced ``` блоки), цитаты-ответы (`↱`) |
| Внизу: поле ввода | многострочное (`Alt+Enter` — перенос строки, `Ctrl+G` — увеличить/уменьшить) |

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `Enter` | отправить сообщение |
| `Alt+Enter` | перенос строки в поле ввода |
| `Ctrl+↑ / Ctrl+↓` | переключение панелей (список → ввод → поиск) |
| `Ctrl+F`, `/` | поиск по чатам |
| `Esc` | вернуться к списку чатов (сбросить поиск) |
| `Ctrl+P` | закрепить/открепить выбранный чат |
| `Ctrl+M` | пометить чат прочитанным |
| `Ctrl+U` | сэмулировать входящее сообщение (демо) |
| `Ctrl+Q` | выход |

## Mock-engine

`src/telegram_tui/engine.py` генерирует 10 чатов (личные, группы, каналы),
историю с код-сниппетами и ответами, входящий трафик каждые ~6 секунд
(`tick()`) и автоответы собеседников на ваши сообщения. Движок детерминирован
при заданном `seed` — удобно для тестов.

Отключить живой трафик: `telegram-tui --no-traffic`.

## Тесты

```bash
pip install pytest pytest-asyncio
pytest
```

Тесты интерфейса выполняются через `textual.pilot` (фокус, навигация
стрелками, хоткеи, отправка сообщений) и включают проверку ресайза терминала
(SIGWINCH): `pilot.resize_terminal()` меняет размер, проверяется, что
рендер не падает и панели остаются работоспособными.
